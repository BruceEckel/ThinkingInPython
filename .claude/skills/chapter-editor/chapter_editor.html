Select text to mark it, then press R to ask Claude to rewrite it (the note box takes what's wrong, if you want to say), D to delete it, or E to edit that paragraph's Markdown yourself. A selection can run across paragraphs. Marks save as you make them. When you've been through the chapter, click Send round and type apply in the Claude Code terminal. The page then reloads with the new text, and each paragraph that changed is outlined in blue, with its previous version one click away.
