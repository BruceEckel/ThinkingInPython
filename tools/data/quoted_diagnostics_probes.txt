# How to rebuild each quoted `ty` diagnostic before checking it.
# One entry per quote: markdown path, the quote's ordinal in that file
# (every quote counted from 1; a block holding two diagnostics counts
# as two), the extracted listing to start from, then one or more edits.
# Fields are separated by tabs. Edits: none, strip-ignore,
# `replace: OLD => NEW`, `delete: TEXT`, `delete-range: A => B`,
# `insert-after: ANCHOR => TEXT`, `append: TEXT`, `uncomment: TEXT`.
# Each anchors on text in the listing, never on a line number, and
# a backslash-n in TEXT starts a new line. An edit reproduces what the
# prose around the quote says the author did: the `# type: ignore`
# removed, a `match` block deleted, a line uncommented, a call appended.
# Written by hand; `tip quoted-diagnostics-probe` reads it and reports
# a quote with no entry. See tools/quoted_diagnostics_probe.py.
