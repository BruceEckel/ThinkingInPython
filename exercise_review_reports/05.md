## Findings

### 1. Exercise 2's solution silently rewrites `get()`'s missing-key behavior, though not asked to

- **Severity:** minor
- **Where:** `Chapters/05_Foundations--Functions.md:502-503` (exercise text)
  and `Solutions/05_Foundations--Functions.md:32-45` (`exercise_2.py`)
- **Exercise says:** "In `sentinel_default.py`, add a third key to
  `prefs`, `"volume2": None`, and call `get(prefs, "volume2")` to
  confirm the sentinel still tells `None`-as-value apart from missing."
- **What actually happens:** The chapter's own unmodified `get()`
  already satisfies the exercise. Running it with only the requested
  addition (`prefs["volume2"] = None`, then `get(prefs, "volume2")`)
  prints `None`, exactly as asked, with no other change:
  ```
  MISSING = sentinel("MISSING")
  def get(data, key, default=MISSING):
      try:
          return data[key]
      except KeyError:
          if default is MISSING:
              return MISSING
          return default
  prefs = {"volume": 3, "mute": None, "volume2": None}
  print(get(prefs, "volume2"))
  ```
  produces `None` (verified with `uv run python`).
- **Solution does:** `Solutions/05_Foundations--Functions.md`'s
  `exercise_2.py` replaces the whole body of `get()`: the
  `try/except KeyError` becomes `if key in data:`, and the missing-key,
  no-default branch changes from `return MISSING` (the chapter's
  documented behavior, with a comment noting a real implementation
  would re-raise) to an actual `raise KeyError(key)`. This is a
  behavioral rewrite of a function the exercise never asked the reader
  to touch — it only asked to add a key and make one call. The
  rewritten version still produces the exercise's requested output
  (verified: `uv run python build/solutions/.../exercise_2.py` prints
  `None`), so the exercise's stated outcome is not false, but the
  solution answers a broader, unstated brief ("also make `get()`
  re-raise for real") on top of the one asked.
- **Suggested fix:** Either narrow `exercise_2.py` back to the
  chapter's `get()` unchanged plus the two requested lines, or, if the
  rewrite is intentional, have the exercise text ask for it explicitly
  (e.g. "and make the missing-key branch raise `KeyError` for real").
